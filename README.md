# Recover the Design - 算法解决方案 (C语言版)

## 📖 项目简介
本项目是对 ZJU-ADS 课程题目 **"8-1 Recover the Design"** 的完整 C 语言解决方案。

**问题背景**：在一个 \(n \times m\) 的矩形网格花园中，原本由水平或垂直的栅栏连接了各个“连接器（Connector）”。连接器上的数字代表它连接的栅栏数量（度数）。现在设计图丢失，只留下了连接器的位置和度数，要求我们恢复出一张合法的栅栏布局图。

**核心约束**：
1. 栅栏必须是水平或垂直的直线，不能弯曲。
2. 栅栏不能在没有连接器的地方交叉。
3. 转角处必须有连接器。

## 🚀 算法原理：行优先回溯法 (Row-Major Backtracking)

本题是一个典型的带约束的图搜索问题。相比于传统的全局搜索，本代码采用了一种极其高效的**行优先（从上到下，从左到右）** 的搜索策略。

### 核心优化策略：
1. **分支因子降维 (\(\le 2\))**：
   将所有连接器按行优先编号为 `0` 到 `V-1`。任何一条边，两端的编号必是一大一小。约定每条边都“归编号小的那一端决定”。
   因此，当处理第 `i` 个连接器时，它**左侧**和**上方**的边必定已经被之前的点决定了。它只需要决定**“向下”**和**“向右”**是否连线。这极大缩小了搜索树。
2. **严格局部剪枝 (`accept` 函数)**：
   在决定连一条边到目标点 `j` 时，立刻检查 `j` 是否还能凑齐它需要的度数：
   - `j` 不能超载（`deg[j] + 1 <= vk[j]`）。
   - `j` 剩下的需求，必须小于等于它未来可能连的边数（右边、下边是否有连接器，以及左边那个尚未处理的连接器是否就是当前点 `i`）。
3. **O(1) 交叉检测**：
   由于是从上到下按行处理，垂直方向的栅栏必定是自上而下依次放置的。代码使用 `vTop` 和 `vBot` 数组记录每一列当前竖直栅栏覆盖的行区间。
   当尝试画一条水平边时，只需检查它穿过的列中，是否存在 `vTop[x] < row && vBot[x] > row`（严格小于/大于，端点相交是合法的）。
4. **奇偶性预判**：
   利用图论握手定理，所有连接器的度数之和若为奇数，直接输出 `No Solution`。

## 📂 代码结构说明

*   `g[MAXD][MAXD]`：原始输入矩阵。
*   `id[MAXD][MAXD]`：将二维坐标映射为一维连接器编号。
*   `vr`, `vc`, `vk`：记录每个连接件的行号、列号和目标度数。
*   `nxtR`, `nxtD`, `prevR`：预处理的邻居数组，记录同列下方、同行右方、同行左方最近的连接件编号。
*   `dfs(i)`：回溯核心，处理第 `i` 个连接件。
*   `accept(i, j)`：落子前的剪枝检查。
