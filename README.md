# Recover the Design - 算法解决方案

## 📖 项目简介
本项目是对 ZJU-ADS 课程题目 **"8-1 Recover the Design"** 的完整 C++ 解决方案。

**问题背景**：在一个 \(n \times m\) 的矩形网格花园中，原本由水平或垂直的栅栏连接了各个“连接器（Connector）”。连接器上的数字代表它连接的栅栏数量（度数）。现在设计图丢失，只留下了连接器的位置和度数，要求我们恢复出一张合法的栅栏布局图。

**核心约束**：
1. 栅栏必须是水平或垂直的直线，不能弯曲。
2. 栅栏不能在没有连接器的地方交叉。
3. 转角处必须有连接器。

## 🚀 算法原理
本题是一个典型的**约束满足问题 (CSP)**，结合了平面图的几何拓扑限制。我们采用 **DFS 深度优先搜索 + 回溯法**，并配合强力的剪枝策略来高效求解。

### 核心优化策略：
1. **预处理最近连接器 (Next Arrays)**：
   由于栅栏不能跨越其他连接器，任何连接器只能与**同行或同列中距离最近的另一个连接器**相连。代码预先计算了每个格子上下左右四个方向最近的连接器坐标（`next_U`, `next_D`, `next_L`, `next_R`），使得寻找候选连线的时间复杂度降为 \(O(1)\)。
2. **MRV 启发式 (Minimum Remaining Values)**：
   在每一步搜索中，不盲目按顺序找点，而是遍历所有尚未满足度数的连接器，计算它们**当前还可以合法连线（即不交叉且目标点有空闲端口）的方向数量**。优先处理**可选方向最少**的连接器。这能尽早触发死胡同（Fail-fast），极大减少搜索树的分支。
3. **局部合法性剪枝**：
   如果某连接器还需要的度数 > 当前可用的合法方向数，则说明当前路径绝对行不通，直接 `return false`。
4. **交叉检测**：
   使用 `h_passes` 和 `v_passes` 两个布尔数组记录网格边上是否有横向/纵向的栅栏穿过。在尝试连线时，若线段中间遇到了垂直方向的栅栏，则视为非法交叉并剪枝。

## 📂 代码结构说明

*   **全局变量**：
    *   `grid[55][55]`: 输入的各点度数。
    *   `rem_deg[55][55]`: 搜索过程中各点**剩余**需要连接的度数。
    *   `used[55][55][4]`: 记录某个点在某方向（0上, 1下, 2左, 3右）是否已经连了线。
    *   `h_passes[55][55]`, `v_passes[55][55]`: 记录边上的占用情况，用于防交叉。
    *   `next_R/L/U/D`: 预处理数组，记录四个方向上最近的合法连接器坐标。
*   **核心函数 `dfs()`**：
    *   寻找剩余度数 \(>0\) 且可选方向最少的点 (MRV)。
    *   若所有点剩余度数均为 0，返回 `true`（找到解）。
    *   尝试向四个方向连线，进行合法性校验。
    *   状态更新（Make） \(\rightarrow\) 递归（DFS） \(\rightarrow\) 状态恢复（Undo/Backtrack）。
*   **主函数 `main()`**：
    *   读入数据。
    *   调用 `dfs()` 寻找解。
    *   根据结果输出：若失败输出 `No Solution`；若成功，则扫描整个网格，输出每个连接器的坐标及四个方向的连接状态。
